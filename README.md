# Final Machine Learning (ML) Project
The project aims to employ ML techniques that can predict how well a game will succeed before release, so that developers can potentially make the necessary improvements that would statistically correlate with game popularity.
## Data Description
Nik Davis's Steam Games dataset on Kaggle (https://www.kaggle.com/datasets/nikdavis/steam-store-games) provides information and statistics about various video game assets for all released video games on the Steam platform as of May 2019. There are nearly 30,000 video game entry rows and 18 feature columns in this dataset.
## Conclusion
The results of this project show that RandomForestRegressor performs slightly better than Linear Regression for predicting the success of games. This suggests that RandomForestRegressor may be a more suitable algorithm for similar tasks.
